# Banking & Finance SQL Analysis

## Project Overview

This project analyzes simulated banking data using MySQL.

The analysis focuses on:

- Customer behavior
- Account activity
- Transaction trends
- Loan analysis
- Monthly financial activity

## Tables

- Customers
- Accounts
- Transactions
- Loans

## SQL Skills

- SELECT
- WHERE
- GROUP BY
- HAVING
- JOINs
- CASE WHEN
- CTEs
- Window Functions
- DENSE_RANK
- ROW_NUMBER
- LAG
- Date Functions

## Dataset

The dataset is synthetically generated for portfolio and SQL
analysis purposes. It does not contain real customer or
financial information.
